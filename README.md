# 巣鴨学園将棋班 夏期合宿 団体戦進行システム (4 vs 4)

## 構成
- **4 チーム総当たり × 3 回戦**
- 各試合は **4 vs 4**（スロット A/B/C/D の 4 面で同時進行）
- **チーム① と チーム② は 5 名登録**で対局毎に 4 名をスロットへ、1 名を補欠として指定
- チーム③・チーム④ は 4 名構成（補欠なし）

## チーム編成
| ID | チーム | メンバー | 補欠枠 |
|---|---|---|---|
| 1 | チーム① | 下田 / 佐藤 / 豊川 / 時 / 池田大翔 | ✓（対局毎に変動可） |
| 2 | チーム② | 小畑 / 小林 / 松井 / 辻井 / 林 | ✓（対局毎に変動可） |
| 3 | チーム③ | 大庭 / 下村 / 川上 / 趙 | – |
| 4 | チーム④ | 秀村 / 山崎 / 熱田 / 小泉 | – |

## 対戦順
| Round | 対戦 |
|---|---|
| 1 | ① vs ② ／ ③ vs ④ |
| 2 | ① vs ③ ／ ② vs ④ |
| 3 | ① vs ④ ／ ② vs ③ |

## 勝敗ルール（前大会方式を踏襲）
| チーム側の総勝数 | チーム結果 | 勝ち点 |
|---|---|---|
| 3勝以上 | 勝利 | +2 |
| 2勝 | 引き分け | +1 |
| 1勝以下 | 負け | +0 |

## 補欠運用（チーム①・チーム②）
- 5名のうち **4名をスロット A〜D へ**、**1名を補欠として別途指名**
- 補欠は **対局毎に自由に変更可**（各回戦「オーダー登録」画面で選択）
- スロット4名はユニーク（重複不可）、補欠はスロット4名と異なる選手
- 補欠選手の個人勝数は集計対象外（ベンチのため）
